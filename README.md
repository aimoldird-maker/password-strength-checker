
# Password Strength Checker

A beginner-friendly Python project that checks password strength using basic security rules.

## Features

- Checks password length (minimum 12 characters).
- Detects uppercase and lowercase letters.
- Checks for numbers and special characters.
- Identifies several common passwords.
- Classifies passwords as WEAK, MEDIUM, or STRONG.
- Hides password input using Python getpass.

## Technologies

- Python 3
- String module
- Getpass module
- Unittest
